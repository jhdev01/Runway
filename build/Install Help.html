Install Runway

About a minute. You only do this once per new version.

  1. Drag Runway onto the Applications folder in the install window.
  2. Copy this command:
    xattr -cr /Applications/Runway.app
  3. Open Terminal: press ⌘ Space, type Terminal, press Return. Paste with ⌘ V and press Return. Nothing prints when it works.
  4. Open Runway from Applications, the Dock, or Launchpad.

Why the Terminal step?

Runway isn't signed with an Apple Developer ID, so macOS marks the downloaded app as quarantined and refuses to open it, sometimes with the message "Runway is damaged and can't be opened". The app isn't damaged. The command removes the quarantine mark. Each new version you download needs it again.
